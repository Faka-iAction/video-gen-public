# Video generation tooling

Remotion-based tooling that renders tutorial and marketing videos. Content tooling only; it has no access to production systems.

Repository: `Faka-iAction/video-gen-public` (FAKA iAction platform, Video generation tooling component).

## Status

Not started. No videos have been produced yet.

## Visibility

This repository is **public**. Everything in it is visible to anyone. It holds only sanitised content: no secrets, credentials, production infrastructure details, risk thresholds or commercial terms.

## Architecture

This component follows the FAKA iAction master architecture. FAKA iAction is the platform; FAKA iRequest is one vertical on it.
